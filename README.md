# TechnoHacks-Internship-Tasks

## 🏥 Patient Feedback Sentiment Analysis Dashboard

An AI-powered Streamlit dashboard that analyzes patient feedback using **Natural Language Processing (NLP)** and **Machine Learning** to measure patient satisfaction and uncover key sentiment trends.

### Features

* Real-time sentiment prediction
* TF-IDF text vectorization
* Logistic Regression classification
* Interactive analytics dashboard
* Sentiment trend visualization
* Positive & negative word clouds
* Simulated patient feedback generation
* Patient satisfaction monitoring

### Tech Stack

* Python
* Streamlit
* Scikit-learn
* Pandas
* Plotly
* Matplotlib
* WordCloud
* NLP

### Dashboard Insights

* Sentiment Distribution Analysis
* Patient Satisfaction Rate
* Longitudinal Sentiment Trends
* Positive Feedback Highlights
* Areas for Improvement Detection
* Review Audit & Monitoring
